Your first training run

This example trains a two-class linear model on synthetic data. Run the snippets in order in one Python process after installing MLZO.

Prepare the data

Section titled “Prepare the data”

Each batch contains inputs of shape [16, 4] and integer targets of shape [16]. A fresh output directory keeps these artifacts separate from earlier runs.

Describe and inspect

Section titled “Describe and inspect”

The plan selects CPU, FP32, and single-device execution. Parameter and memory information that requires model construction remains unknown. Neither train() nor plan() invokes the nn.Linear factory.

Fit and evaluate

Section titled “Fit and evaluate”

The run completes eight algorithm iterations across two epochs. With the default accumulate=1, each iteration requests one optimizer update. The history retains scalar records; evaluation returns averaged scalar metrics under evaluation mode without updating weights.

Save and resume

Section titled “Save and resume”

epochs=3 is the total target, so this resumes for one more epoch. Checkpoints restore model, optimizer, scheduler, RNG, algorithm state, and counters. This example saves at an epoch boundary. A mid-epoch checkpoint restarts that data epoch rather than replaying an exact sampler position.

Export and predict

Section titled “Export and predict”

The artifact stores inference weights and an importable nn.Linear construction recipe. It is separate from the resumable checkpoint. deploy() loads a synchronous predictor in this process; it does not start a server. See checkpoints and inference artifacts for the storage contracts.
